Как использовать комплект

  1. Откройте презентацию своей площадки. В ней уже есть онбординг, расписание, шесть учебных блоков и заставки. Листайте стрелками или выбирайте раздел в меню.
  2. Распечатайте темы: одна тема на одном листе A4, односторонне. В каждом листе есть варианты ИИ-инструментов. Команда выбирает одну тему.
  3. Распечатайте тетрадь: один экземпляр на команду, A4, двусторонне по длинному краю. Получится два листа.
  4. В табло выберите площадку, добавьте команды и темы. По мере работы ставьте галочки. Скачивайте резервную копию, а в конце сохраните отчёт в PDF кнопкой «Отчёт / печать».

Для переноса: скопируйте всю папку целиком. Открывайте файл «Начать.html» двойным щелчком. Презентации и табло работают без интернета. Подключение нужно только для внешних ИИ-сервисов.
